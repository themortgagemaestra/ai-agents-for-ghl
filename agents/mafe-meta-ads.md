## Real campaign structure — from Bobby (Tiffany Rose's Meta ads expert), 9/4/26

Gathered from a live coaching-call transcript Jess shared, not a direct Jess interview — treat as expert-sourced guidance to apply, not something to re-confirm with Jess before using, but flag it as Bobby's recommendation (not Jess's own words) if it ever conflicts with something she says directly.

**Campaign architecture:** 4 angles × 4 ads per angle = **16 ads total, all inside one ad set, inside one campaign** — not 16 separate ad sets, not a per-ad budget split. An "angle" is a different subject/audience cut on the same product (e.g., for the Digital HELOC: self-employed/business-owner equity access, "you have more equity than you think," a state-specific cut, a specific pain point like debt consolidation or home repairs) — 4 ads get made per angle. Budget is set at the **campaign level**; Meta's algorithm auto-distributes spend across all 16 based on performance. One ad set for all 16 matters specifically because NCF is in Meta's **Special Ad Category** (housing/mortgage) — demographic targeting is restricted, so Meta's own AI ("Andromeda") reads the creative itself to find the audience; fragmenting into more ad sets just fragments the learning data Meta needs to do that well. NCF's confirmed $75–100/day budget comfortably covers this structure.

**Skip Meta's native lead form — use a real landing page.** Directly answers the open A/B test question below: Bobby's expert take is don't test it, don't use it — Meta's own lead form gets cheaper but junk leads (people don't remember filling it out, get annoyed when called, exactly what Jess already experienced). Build a real landing page instead: message must correlate tightly to the ad itself, add a Meta Pixel in the page header (GHL makes this easy) so performance data flows back to Meta, add Microsoft Clarity (free) for heatmaps/drop-off visibility. This doesn't override Jess's own final call, but it's a real, informed recommendation against the current "test both" plan below.

**Ad-level settings to check on every ad:** turn OFF Meta's auto-added music (unpredictable, has drawn complaints), auto-crop (breaks caption framing), auto-translate/dub (can silently push the ad in up to 14 languages), and the auto-overlay/link optimization. Leave ON: relevant comments, enhanced CTA, text improvements, auto-brightness. Verify the site link actually points to the landing page — Meta sometimes swaps it for the account's root domain. Turn off Advantage+ unless deliberately wanted.

**Metrics to actually watch:** CTR, and specifically **Link CTR** (not just ad clicks). CPC / cost per link click. **CPM** — Bobby's the one metric he said everyone should watch; an unexplained CPM spike usually means creative fatigue or a targeting problem. Frequency (same-person repeat views).

**Monitoring cadence:** hands off the first 3 days, unless one specific ad is wildly overspending with zero leads (his example: $120–150, nothing). No real cuts before ~1.5 weeks — Meta's learning phase needs volume to optimize. Let a creative set run about a month before rotating in new ads.
