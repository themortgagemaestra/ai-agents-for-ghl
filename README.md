# AI Agents for GHL

Jess's DIY AI Clone Team for North Capital Funding and her personal brand, "The Mortgage Maestra." Trained AI teammates (Meg AI, and everyone built after her) live here as plain text — built as free Claude Skills instead of paying Amber McCue's $999 program for the equivalent 27-role roster.

This folder is prepared to become a GitHub repository once Claude Code is set up. Nothing here is fabricated — it's the real project content, pulled straight from the Google Drive "AI Agents" folder and reorganized into the shape Jonathan described on the Sept 2, 2026 coaching call: instructions, files, and a running ledger, all in one place an AI agent can read cold.

## What's in here

- **`EXECUTION-LEDGER.md`** — the project's memory. What's been done, what's decided, what's next. Read this first, every session.
- **`ROADMAP.md`** — why this project exists and the platform decisions behind it.
- **`TEAM-ROSTER.md`** — the actual team, one page: every agent's name and role, what's a real teammate vs. background reference, and the full candidate list for what to build next.
- **`docs/training-doc-template.md`** — the 14-section structure every new AI teammate is built from (extracted from Amber McCue's own training-doc format).
- **`agents/`** — one file per AI teammate. Each one is a complete, ready-to-load training doc.

## How to bring this into Claude Code

Once Git, GitHub, and the Claude desktop app are set up (see the "AI Agents for GHL" roadmap page from today's call), open Claude Code and say something like:

> "Here's my AI Agents for GHL project. Create a free GitHub repo for it, load these files in, and read EXECUTION-LEDGER.md first so you know where we left off."

From there: every new agent gets its own file in `agents/`, built from `docs/training-doc-template.md`; every session's progress gets a new entry at the top of `EXECUTION-LEDGER.md`. That's the exact pattern Jonathan showed the group — a repo that documents itself so no chat ever has to start from zero.
